# saumux v0.3.0

The bundled editor gains automatic syntax highlighting and a proper Save As
file dialog. Linux and macOS remain supported on Intel and ARM.

## Highlights

- **Syntax highlighting:** keywords, strings, numbers and comments are coloured
  automatically for Rust, C/C++, Java, Go, C#, JavaScript/TypeScript, Python,
  shell scripts, JSON and TOML. Colours follow live theme changes, and Save As
  re-detects the language from the new filename. Other file types stay plain text.
- **Save As file dialog:** browse folders, select an existing file or enter a new
  filename, with keyboard and mouse controls. Tab/Shift+Tab moves focus; arrows
  select entries; Enter opens a folder, chooses a file or saves from the filename
  field. Esc cancels. Cancelling overwrite confirmation restores the chooser
  with the selected filename.
- **Readable themed controls:** a clear border and separators, bold folder names,
  distinct input/button surfaces and a highlighted active field. The title and
  accents follow the theme; light/dark document surfaces preserve readability.
  All chooser and syntax text roles pass the contrast audit across all 15 themes
  against the bundled browser palette.

UTF-8 editing, undo/redo, unsaved-change prompts, atomic saving, preserved line
endings/permissions and external-change detection remain in place.

## Downloads and upgrading

Four archives are provided, with checksums in `SHA256SUMS`:

- Linux Intel/AMD 64-bit: `x86_64-unknown-linux-musl`
- Linux ARM 64-bit: `aarch64-unknown-linux-musl`
- macOS Intel: `x86_64-apple-darwin`
- macOS Apple Silicon: `aarch64-apple-darwin`

Extract the appropriate archive and run `saumux`. Linux binaries are statically
linked with musl. Start a new named session to load the updated server; existing
sessions keep their running code and programs.

Highlighting is lightweight lexical colouring, without language-server features.
Markdown, batch files and Notes preview code blocks remain unhighlighted. Editor
autosave and crash recovery are not included.
