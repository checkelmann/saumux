# saumux v0.2.0

saumux now brings the same retro terminal desktop to a browser, with coding-agent
launchers, saved projects, a Markdown notebook and more live colour themes.
Linux and macOS remain supported on Intel and ARM.

## Highlights since v0.1.0

- **Browser frontend:** `saumux web` serves the shared desktop with embedded,
  offline assets, mouse and keyboard controls, clipboard fallback and reconnect.
  Terminal and browser clients can use the same session; disconnecting leaves
  programs running. A bundled symbols font supports Powerline prompts.
- **Coding agents and projects:** discover and launch eight common coding-agent
  CLIs, save project directories and see visual attention notices across windows
  and workspaces. Ctrl+g opens the attention list.
- **Live themes:** switch among fifteen palettes without restarting programs.
  Desktop and bundled apps update together, and the choice persists for future
  sessions. New palettes include Matrix, Atari and Tokyo.
- **Bundled apps:** System Monitor shows real CPU and memory readings, CPU history
  and per-core meters. Clock supports local/UTC and 12/24-hour display.
- **Markdown Notes:** searchable notes, styled previews with tables and task
  lists, inline editing, protected saves and deletion confirmation. Notes remain
  ordinary files on disk.
- **Dual-panel files:** browse two directories, mark files, copy, move, rename,
  delete, create directories and preview text, image metadata or binary data.
  Open text files in the bundled editor.
- **Desktop improvements:** title-bar minimization, a persistent attention badge,
  preserved Shift/Control+Enter input and sessions that stay open after their
  last window closes.

## Downloads

Choose the archive for your platform, extract it and run `saumux`:

| Platform | Archive target |
| --- | --- |
| Linux Intel/AMD 64-bit | `x86_64-unknown-linux-musl` |
| Linux ARM 64-bit | `aarch64-unknown-linux-musl` |
| macOS Intel | `x86_64-apple-darwin` |
| macOS Apple Silicon | `aarch64-apple-darwin` |

Linux executables are statically linked with musl. `SHA256SUMS` contains checksums
for all four archives. Each archive includes the license, third-party notices,
documentation and optional terminfo entry.

## Browser access

`saumux web` listens on **0.0.0.0:8080 without authentication or built-in TLS**.
Anyone who can reach the listener can operate the session as its owner. Use
`saumux web --bind 127.0.0.1` for local-only access, or supply access controls and
HTTPS through a reverse proxy.

## Limits

This remains an early implementation. Sessions survive client disconnects, not
server crashes or reboots. Saved layouts restart commands rather than checkpointing
program state. The editor has no autosave or crash recovery; agent prompt detection
is best effort, and browser touch/mobile input has not been validated.
